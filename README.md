# GVIH LaTeX Two-Column Template

[![README](https://img.shields.io/badge/English-blue.svg)](README.md)
[![README](https://img.shields.io/badge/中文-red.svg)](README.zh.md)

## 1. Introduction
GVIH is a lightweight two-column LaTeX template, with less than 300 lines of code overall, designed for organizing and publishing two-column SCI papers.

## 2. Core Files

```
├── README.md       English documentation
├── README.zh.md    Chinese documentation
├── base.cls        Document class definition
├── main.tex        Main paper content (edit this file)
├── ref.bib         Reference database
├── start.sh        One-click compilation script
├── figures/        Image directory
└── main.pdf        Final output (generated by running start.sh)
```

## 3. Execution

### 3.1 One-Click Execution
Run in terminal:
```bash
bash start.sh  # Automatically compiles everything and generates main.pdf
```

### 3.2 Manual Compilation
Run these commands in sequence:
```bash
xelatex main.tex   # First compilation - generates main content
biber main         # Reads references from .bib file
xelatex main.tex   # Imports reference list
xelatex main.tex   # Updates citation numbers in text
```

### 3.3 GUI Editor Execution
In Overleaf, ShareLaTeX, or other LaTeX editors, run: `XeLaTeX → Biber → XeLaTeX → XeLaTeX`

## 4. File Preparation
* `main.tex` — Main paper content, edit this file according to section 5 below
* `ref.bib` — Reference database. Use tools like Zotero or EndNote to export references as BibTeX format.
* `figures/` — Image directory for storing paper images.

## 5. Writing Guide

### 5.1 Title

```latex
\settitle{Paper Title}
```

### 5.2 Author Information

```latex
\authorsinfo{Yangxiu Liu\orcidlink{0000-0003-4759-1955}\textsuperscript{1*}}
\authorsunit{Beijing Esoul AI Information Technology Company Limited\textsuperscript{1}}
\corremail{email: liuyangxiu@alu.cau.edu.cn\textsuperscript{1}}
\printtitle
\printauthors
```

### 5.3 Abstract & Keywords

```latex
\begin{abstract} ... \end{abstract}
\begin{keywords} keyword1, keyword2 \end{keywords}
```

### 5.4 Section Headings

```latex
\section{Level 1 Heading}
\subsection{Level 2 Heading}
\subsubsection{Level 3 Heading}
```

### 5.5 References
```latex
\cite{key}                                  % Single reference
\cite{key1,key2}                            % Multiple references
```

### 5.6 Images

| Command | Purpose | Syntax |
|---------|---------|--------|
| `\singlefigure` | Single column | `\singlefigure[width]{path}{caption}{label}` |
| `\widefigure` | Double column | `\widefigure[position]{width}{path}{caption}{label}` |

**Position parameters**: `t`=top, `b`=bottom, `tb`=auto (default)

**Example**:
```latex
\singlefigure[0.9]{figures/figure2.png}{Single column figure.}{fig:single}
\widefigure[tb]{0.9}{figures/figure1.png}{Wide figure spanning both columns.}{fig:wide}
```

### 5.7 Tables

| Command | Purpose | Syntax |
|---------|---------|--------|
| `\singletable` | Single column | `\singletable{number}{colwidths}{title}{header}{content}` |
| `\widetable` | Double column | `\widetable[position]{number}{colwidths}{title}{header}{content}` |

**Position parameters** (optional): `t`=top, `b`=bottom, `tb`=auto (default)

**Example**:
```latex
\widetable[tb]{Table 1}{0.33,0.33,0.34}{Characteristics Comparison}{\textbf{Feature} & \textbf{Y chr} & \textbf{X chr}}{%
Mutation rate & High & Medium \\
Gene density & Low & High \\
Evolution rate & Fast & Slow
}
```

### 5.8 Equations

| Command | Purpose | Syntax |
|---------|---------|--------|
| `\singleequation` | Single column (numbered) | `\singleequation{formula}{eq:label}` |
| `\wideequation` | Double column (numbered, spanning) | `\wideequation[position]{formula}{eq:label}` |

**Position parameters** (optional): `t`=top, `b`=bottom, `tb`=auto (default)

**Example**:
```latex
\singleequation{E=mc^2}{eq:emc}       % Single column with numbering
\wideequation[tb]{\frac{dx}{dt} = \mu_Y\delta_{j,Y} + T_{j-1 \rightarrow j}x_{i,j-1}}{eq:core}     % Double column spanning
```

## 6. FAQ
1) Q: Images are automatically moved causing large blank spaces?
A: Adjust text content and positions to accommodate images.

2) Q: Wide figures/tables/equations go to next page?
A: Move them closer to related text on the previous page.

3) Q: How to get reference .bib files?
A: Use Zotero, EndNote, or similar tools to export references as BibTeX.

4) Q: How to change reference style?
A: Modify `style=numeric` in `base.cls`, e.g., `style=gb7714-2015` for GB/T 7714 format.
